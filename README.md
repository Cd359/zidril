# Zidril - Movie & Series Search

A modern movie and series search application built with Next.js 15.

## Features
- 🔍 Search for movies and TV series
- 🎬 Watch movies directly in the app
- 🔥 Trending movies on homepage
- 📱 PWA support for mobile installation
- 🎨 Beautiful responsive design

## Tech Stack
- Next.js 15
- TypeScript
- Tailwind CSS
- PWA

## Deploy on Vercel

1. Push this project to GitHub
2. Import the repository in Vercel
3. Deploy!
